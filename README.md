How do you write programs that are maintainable, readable, and adaptable? Especially consider your work on the CRUD Python module from Project One, which you used to connect dashboard widgets to the database in Project Two. What were the advantages of working in this way? How else could you use this CRUD Python module in the future?

The fastest way to learn how to write programs that are maintainable, readable, and adaptable is to use references on industry standards from an autoreactive source. For me I study Python Crash Course by Eric Matthes to learn the fundamentals and Mastering MongoDB 6.x by Alex Giamas. The DNA on how write working code in Python and using the NoSQL database program, MongoDB. Considering my CRUD Python module there was room for iteration and using my instructor’s input I could solve issues with my code. Some examples being broken else statements and Indentation errors that invalidated functionalities in my module. Once I started working on my dashboard, I could concentrate all my efforts on it rather than iterating the CRUD Python module. The main advantage being that I could work on the foundation of my previous work rather than working on both projects at the same time.

The way I approached this project as a computer scientist was to study the requirements layout by the client, doing research, writing code, testing my code, documenting errors, and iterating until my application ran as desired based on the client’s requirements. Working on future projects like these would certainly require more mindfulness as syntax and indentation are key issues I have with environments that do not allow customized plug-ins which is something that can happen in a work only virtual environment like codio.

Computer scientists are designers of systems that allow clients or organizations to manipulate data in the digital age. The field spams a wide variety of disciplines but pertaining to Grazioso Salvare’s project the main job of a computer scientist is to create the infrastructure for their mission to be done. In this case creating a framework for them to easily interact with their massive database of animals for rescue training. From creating something like the CRUD module that can easily be paired with multiple applications to access the datasets of AAC. Creating pipelines for information to be securely delivered to the organization’s users. In general the making their job’s easier by simplifying complex query tasks into filters.
